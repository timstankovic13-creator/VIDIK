# VIDIK Municipal Retrospective & Shadow Casebook

## Evidence discipline
These are **retrospective/shadow demonstrations**, not live pilots. VIDIK does not claim to have caused any observed municipal outcome.

## Ottawa — housing
- Jurisdiction: Ottawa, Ontario, Canada
- Intervention family: Housing First / supportive housing
- Historical source family: City of Ottawa housing and homelessness reporting
- Retrospective question: What recommendation would VIDIK produce using only evidence available at the historical decision date?
- Shadow comparison: VIDIK recommendation vs. actual municipal decision
- Outcome status: historical observational evidence only; not a VIDIK-attributed outcome
- Learning status: eligible for future real longitudinal observation

## Required case record fields
Each executable case should record: decision date, source IDs, source publication dates, retrieval dates, evidence claims, normalized parameters, VIDIK recommendation, alternatives, actual municipal decision, implementation record if publicly documented, outcome metric/unit/date, provenance, temporal-leakage result, recommendation divergence, uncertainty, and audit identifier.

## Acceptance rule
If a source is published after the historical decision date and materially informs the recommendation, the retrospective reconstruction must fail closed rather than silently using the leaked information.

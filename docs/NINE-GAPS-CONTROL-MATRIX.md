# Nine-gap control matrix

1. Trusted evidence quality metadata.
2. Duplicate evidence identifiers rejected.
3. Freshness/staleness admissibility gate.
4. Missing evidence fails closed.
5. Resource/currency unit compatibility.
6. Explicit authorized audited human override.
7. Partial source outage isolation with available results preserved.
8. Multi-dimensional transferability assessment with no causal effect import.
9. Independent wrong-jurisdiction evidence rejection.

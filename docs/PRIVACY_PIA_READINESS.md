# VIDIK Privacy / PIA Readiness Checklist

Use this checklist with municipal privacy counsel/privacy officers. It is not legal advice and does not constitute a completed Privacy Impact Assessment.

## Data inventory
- [ ] List every data element ingested, generated, exported, and logged.
- [ ] Classify each element as public, internal, confidential, or personal information.
- [ ] Identify source, purpose, lawful authority/contract basis, owner, and retention period.
- [ ] Identify all users, roles, recipients, and subprocessors.

## Data flows
- [ ] Document source → ingestion → normalization → model → decision record → export.
- [ ] Identify every storage location and geographic region.
- [ ] Identify transfers outside the municipality/jurisdiction.
- [ ] Document deletion, correction, backup, and restoration behavior.

## Privacy safeguards
- [ ] Data minimization.
- [ ] Role-based access and least privilege.
- [ ] Authentication and administrative access controls.
- [ ] Encryption in transit/at rest where applicable.
- [ ] Audit logging.
- [ ] Retention/deletion enforcement.
- [ ] Incident detection and notification procedure.
- [ ] Vendor/subprocessor controls.

## Decision governance
- [ ] Explain what VIDIK recommends and what remains a human decision.
- [ ] Preserve evidence and provenance supporting consequential recommendations.
- [ ] Record uncertainty, alternatives, overrides, and override rationale.
- [ ] Provide a process for reviewing errors, drift, and model changes.
- [ ] Test for inappropriate use of personal or sensitive attributes.

## Ontario municipal deployment
The municipality's privacy officer/counsel should determine whether and how a PIA is required under the applicable Ontario framework and municipal policies before deployment involving personal information. The completed PIA and any required agreements remain deployment-specific.

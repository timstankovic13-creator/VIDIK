# Ottawa Evidence Inventory v1

## Intake chain
Source → retrieval → provenance → schema validation → freshness → transportability → reconciliation → immutable snapshot → evidence graph → parameter derivation → decision.

## Priority families
- Population/geography
- Demographics and socioeconomic context
- Police/public safety
- Municipal finance/budgets
- Transportation/road safety
- Emergency/health capacity
- Housing/community services

## Acceptance rule
A source is not decision-driving merely because it is reachable. It must have identifiable publisher, canonical location, retrieval time, reference period, geography, claims, derivation and freshness/transportability status.

## Live phase
Use Ottawa public sources where legally and technically appropriate. Keep live credentials/configuration outside source control. Record every retrieval and reconciliation result.

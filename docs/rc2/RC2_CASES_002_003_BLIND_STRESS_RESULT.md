# RC2 Blind Stress Result — Cases 002–003

**Decision boundary:** `2023-12-06`
**Historical status:** frozen `NO RECOMMENDATION / BLOCKED`
**Current-learning status:** evidence enriched; no retroactive promotion.

## 1. Evidence ceiling

Cases 002 and 003 have strong later quantitative outcome signals, but the RC2 governance gate still blocks historical model eligibility because later outcomes cannot fill missing historical causal stages. Current-learning evidence can support a new decision only after its own as-of date and evidence snapshot are established.

## 2. Common-unit comparison status

A valid comparison requires a common marginal resource unit. Current evidence does not yet supply one:

- ASE: program-level operating/admin cost is reported, but a defensible incremental cost per additional camera/site is not established.
- Paramedic capacity: staffing counts are reported, but a defensible incremental cost-to-capacity production function for one additional FTE/vehicle is not established.

Therefore no cross-intervention benefit-per-dollar ranking is asserted.

## 3. Adversarial stress gate

The deterministic stress harness runs baseline, strongest-evidence removal, uncertainty widening, correlated-error, conflict, transportability, staleness, priority, status-quo, and alternative scenarios when scored evidence is supplied.

**Promotion rule:** any recommendation flip is a failure of recommendation stability and must remain unpromoted until the source uncertainty is resolved or the decision is explicitly presented as sensitivity-dependent.

The test suite deliberately includes both a flip case and a stable case so the harness proves it can detect instability rather than merely assert stability.

## 4. Outcome-learning gate

A promoted current decision must preserve an immutable decision snapshot and define baseline plus 6-month, 1-year, 2-year and 5-year checkpoints. Missing checkpoints block outcome-learning readiness.

For Cases 002–003, current observations are sufficient to populate early learning signals, but they are not a substitute for a recommendation-grade causal model.

## 5. Result

**Cases 002–003: NO RECOMMENDATION / BLOCKED.**

This is the intended fail-closed result. The RC2 work has now advanced the evidence layer, quantitative evidence registry, blind stress validation, and outcome-learning gate without contaminating the RC1 historical freeze.

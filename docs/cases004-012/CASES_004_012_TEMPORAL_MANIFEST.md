## Admissibility rule
Only evidence published and genuinely available on or before 2023-12-06 may drive the blind historical run. Later implementation reports, outcomes, evaluations, and budget decisions are sealed validation-only material.

## Batch rule
Cases 001–012 are run without exposing actual later outcomes or later municipal decisions to the recommendation stage. Any missing candidate-specific marginal chain stage forces **NO RECOMMENDATION — BLOCKED**.

## Case construction rule
Each case contains a real candidate, a real pre-boundary source family, and a minimal admissible resource/capacity/activity chain. The absence of a defensible candidate-specific outcome/system-outcome counterfactual is recorded rather than filled by assumption.

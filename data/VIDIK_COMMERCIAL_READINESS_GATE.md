# VIDIK Commercial Readiness Gate v1

This is the gate for moving from a technically credible prototype to a product that can be sold and supported.

## A. Product

- [ ] Canonical question → evidence → analysis → answer workflow works without developer intervention.
- [ ] Answer-first decision view is stable.
- [ ] Why / Why-not / alternatives / uncertainty / assumptions are understandable to a municipal decision-maker.
- [ ] Recommendation, decision-support, and no-recommendation states are visually distinct.
- [ ] Human override is explicit, reasoned, and auditable.

## B. Evidence

- [ ] Minimum Sufficient Evidence is enforced.
- [ ] Historical and current-learning planes remain separate.
- [ ] Public data are never represented as operational exposure merely because aggregates exist.
- [ ] Acquisition requests are scoped to frozen causal requirements.
- [ ] Evidence failures fail closed.

## C. Reliability

- [ ] Decision object is immutable after historical freeze.
- [ ] Inputs and evidence have stable identities.
- [ ] Repeated execution is deterministic.
- [ ] Audit export is complete.
- [ ] Failure registry captures material failures.
- [ ] Benchmark reports latency, manual effort, stability and block rates.

## D. Security / procurement

- [ ] Tenant isolation tested.
- [ ] Authentication/authorization boundaries documented.
- [ ] Data retention and deletion policy defined.
- [ ] Privacy-preserving operational-data specification defined.
- [ ] Audit logging and export documented.
- [ ] Incident/support process documented.
- [ ] Procurement/security questionnaire package prepared.

## E. Commercial proof

- [ ] At least one bounded customer-style workflow completed end-to-end.
- [ ] Existing workflow baseline captured.
- [ ] VIDIK-assisted workflow measured against baseline.
- [ ] Turnaround claim based on benchmark distributions, not anecdotes.
- [ ] Human decision-maker remains accountable for the authorized decision.
- [ ] Pilot scope, deliverables, success metrics and pricing are defined.

## Current status

**Engineering/evidence architecture:** strong foundation.

**Commercial gate:** not yet passed until a real prospective/shadow workflow supplies measured turnaround and human-work reduction.

No claim of commercial readiness should be made solely from CI or synthetic tests.

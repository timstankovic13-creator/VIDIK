# VIDIK Municipal Reference Data

This directory contains controlled reference-data artifacts and fixtures. Authoritative upstream datasets must be imported through `scripts/municipal-reference-pack.js`; raw downloads are not treated as decision-driving evidence merely because they exist locally.

## Priority datasets

1. Statistics Canada 98-10-0002-02 — Census municipal population/dwellings/geography baseline.
2. Statistics Canada 17-10-0155-01 — annual population estimates.
3. Statistics Canada 35-10-0077-01 — municipal police/public-safety statistics.
4. Statistics Canada 2021 Census Profile — demographic/socioeconomic baseline.

## Required validation

Every full import must pass CSV/schema validation, CSD identifier validation, duplicate detection, numeric/range validation, suppression/missing-value handling, reconciliation to the WUP municipal spine, deterministic normalization, source/output hashing, and provenance generation.

## Current status

The repository contains a real Ottawa source-format fixture and automated ETL validation. Full upstream national extracts are intentionally generated by the importer from the authoritative downloaded/API artifacts rather than committed blindly.

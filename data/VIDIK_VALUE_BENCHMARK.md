# VIDIK Value Benchmark

Compare a conventional municipal workflow with the same question run through VIDIK. Measure, rather than assume:
- elapsed time to decision-ready package;
- analyst hours;
- material evidence gaps identified;
- inappropriate recommendations avoided/refusals correctly issued;
- opportunity-cost analyses surfaced;
- sensitivity/flip analyses completed;
- audit completeness and reproducibility.

A commercial value claim is **not passed** until a real prospective or shadow workflow supplies observed paired measurements. Synthetic lab performance cannot establish customer ROI.

# Demo Package

## Five-minute proof
1. Start with a municipal $5M resource-allocation question.
2. Show the status quo and candidate universe.
3. Show evidence lineage and what is actually admissible.
4. Run allocation under explicit synthetic benchmark assumptions.
5. Stress the result and show a recommendation flip / refusal where appropriate.
6. Show Why / Why-not and opportunity cost.
7. Show immutable decision snapshot, human override and audit trail.
8. Show the missing real-world evidence required before production recommendation.

The demo must visibly label synthetic benchmark assumptions and must never imply that benchmark effect sizes are Ottawa/Toronto/Melbourne empirical results.

# VIDIK Scope Control v1

This branch is intentionally limited to business-readiness and evidence-governance work that can be validated without CI.

It does not authorize:

- municipal data requests;
- historical decision mutation;
- unsupported effect estimates;
- production claims based solely on local tests;
- GitHub Actions reruns without a named release-gate purpose.

Any future expansion beyond this scope requires a new explicit release/experiment gate.

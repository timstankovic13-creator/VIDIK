# VIDIK Demo Acceptance v1

A customer demo is accepted only if the same workflow can demonstrate both a supported answer and an evidence-limited block.

## Supported-answer path

Question locked → admissible evidence → model → counterfactual → analysis → recommendation → Why/Why-not → human decision → immutable audit snapshot.

## Blocked-answer path

Question locked → evidence scan → material gap identified → `NO RECOMMENDATION` → exact failed gate → minimum evidence needed → no invented estimate.

## Acceptance assertions

- no developer intervention;
- no hidden evidence substitution;
- no post-boundary historical leakage;
- no aggregate-to-marginal substitution;
- no human override mutation of VIDIK output;
- complete decision identity and audit record.

# Evidence Acquisition Pipeline

Turn each blocked decision into a minimum, ranked acquisition package.

## Pipeline
1. Define the exact claim and decision unit.
2. Freeze temporal admissibility.
3. Generate Minimum Sufficient Evidence (MSE).
4. Classify each field: PUBLIC_AVAILABLE, PUBLIC_GAP, MUNICIPAL_REQUEST, or NOT_MATERIAL.
5. Rank missing fields by materiality and expected decision impact / VOI.
6. Generate a precise request package only for material gaps.
7. On return, validate provenance, timing, exposure, comparator and measurement readiness.
8. Promote claim level only when its gate passes; otherwise remain descriptive/decision-support or blocked.

## Current highest-value real acquisition targets
- 009 ASE: comparator/control history + concurrent interventions + collision linkage.
- 010 RLC: comparator/control history + concurrent interventions + collision linkage.
- 014 Shelter: marginal bed-night exposure + comparable demand/capacity shock.
- 006 ANCHOR: eligible-call exposure/assignment + comparable calls/areas + downstream outcomes.

No request is treated as evidence merely because it was requested; returned records remain subject to admissibility checks.

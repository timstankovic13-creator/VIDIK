# VIDIK Commercial Handoff Checklist v1

Before a pilot is called ready:

- customer decision class is defined;
- baseline workflow and analyst effort are measurable;
- municipal adapter is configured;
- evidence sources and permissions are mapped;
- MSE package is frozen for the decision class;
- output package is agreed with the customer;
- human decision/override process is understood;
- audit/export requirements are documented;
- outcome owner and review checkpoints are assigned;
- success criteria are pre-registered.

This checklist separates **product readiness** from **customer proof**. Passing it means the pilot can be run cleanly; it does not mean commercial value has already been proven.
